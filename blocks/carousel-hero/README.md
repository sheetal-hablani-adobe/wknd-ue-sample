# carousel-hero

Custom **carousel** block. Purpose: full-bleed rotating hero at the top of the home page, one promoted story per slide.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide; cell 1 = slide image (with alt), cell 2 = h2 title, description paragraph and CTA link.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
