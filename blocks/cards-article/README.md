# cards-article

Custom **cards** block. Purpose: row of image cards each linking to an article or adventure detail page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card; cell 1 = card image (with alt), cell 2 = title as linked heading/strong and description paragraph.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
